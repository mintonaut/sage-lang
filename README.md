# 🍃 The Sage Language
---

Compiler for Sage, an experimental C-like programming language featuring strong typing and a typed channel-based concurrency model. Currently implemented in OCaml (project `sageboot`) under `boot/`

> [!Warning]
> This project is in active development, and is in its early stages. Bugs, missing features and erroneous behavior are to be expected while the core software frameworks are being developed.
