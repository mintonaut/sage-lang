# 🍃 The Sage Language

Compiler for Sage, an experimental Rust-like programming language featuring strong typing and a typed channel-based concurrency model. Currently implemented in OCaml (project `sageboot`) under `boot/`.

> [!Warning]
> This project is in its infancy and is actively being developed. Bugs, missing features and erroneous behavior are to be expected while the core software frameworks are being developed.
